Instruções para gerar ícones PWA

Use uma ferramenta online como realfavicongenerator.net ou o pacote npm pwa-asset-generator para gerar os PNGs a partir do SVG.

Comando: npx pwa-asset-generator public/icons/icon.svg public/icons --background "#1e40af" --padding 10%

Arquivos necessários:

  • icon-192.png (192x192)
  • icon-512.png (512x512)
  • apple-touch-icon.png (180x180)
